## 5. ACTIONS HUMAINES REQUISES

Pour activer la generation reelle, executer sur la machine Windows :

1. Démarrer ComfyUI :
   C:\TikTokHistoryFactory\ComfyUI\run_nvidia_gpu.bat
   (ou .\scripts\start_comfyui.ps1)

2. Telecharger un checkpoint manga :
   civitai.com → recherche "SDXL manga"
   → copier dans ComfyUI\ComfyUI\models\checkpoints\

3. Telecharger Wan 2.2 TI2V-5B :
   huggingface.co/Wan-AI/Wan2.2-T2V-5B
   → copier dans ComfyUI\ComfyUI\models\diffusion_models\

4. Installer Piper TTS :
   Executer tools\install_piper.ps1
   ou telecharger manuellement depuis github.com/rhasspy/piper

5. Configurer Ollama Cloud :
   Editer .env et renseigner OLLAMA_API_KEY

6. Lancer un pilote :
   .\scripts\main.ps1 -Mode pilot
